<h1 align="center">PowerTools</h1>

<p align="center">
  <a href="README.md">English</a> | <b>Русский</b>
</p>

---

PowerTools — небольшая нативная программа для очистки и настройки Windows 10/11. Она удаляет встроенные приложения и фоновый мусор, отключает рекламу и рекомендации, настраивает схему питания и визуальные эффекты на скорость и добавляет то, чего нет в Windows: перемещение и изменение размера любого окна мышью из любого места и свои горячие клавиши.

Программа живёт в трее. При закрытом окне в памяти остаётся только движок хоткеев.

Твики сгруппированы по назначению:

- **UWP-приложения**: удаляет все приложения из Store и встроенные, кроме Windows Terminal, Параметров и компонентов, нужных системе. Приложения драйверов GPU и звука, кодеки, Безопасность и Store защищены, пока вы их не разблокируете. Удалённые приложения можно вернуть из программы.
- **Реклама и рекомендации**: «Рекомендуем» в Пуске, поиск на панели задач и Bing, виджеты, Copilot и Recall, подсказки на экране блокировки, рекламный идентификатор, баннеры в Проводнике.
- **Фоновый мусор**: телеметрия и оценщик совместимости, история действий, фоновые приложения, Game Bar, фоновый режим Edge, отчёты об ошибках.
- **Память (ОЗУ)**: OneDrive, оптимизация доставки, SysMain, индексатор поиска, Xbox, геолокация и другие редко нужные службы.
- **Производительность**: схема питания «Максимальная производительность» и визуальные эффекты на максимальную скорость, при этом остаются содержимое окна при перетаскивании, сглаживание шрифтов и прозрачный прямоугольник выделения.
- **Кастомизация**: расширения файлов, скрытые файлы, классическое контекстное меню, ускорение мыши, окна залипания клавиш.

Для каждого твика видно, включён он или выключен, и откатить его можно тем же переключателем.

Использование
-------------

1. Запустите `PowerTools.exe` и подтвердите запрос UAC. Права администратора нужны, чтобы удалять приложения, менять службы и ставить хуки ввода.
2. Включайте твики по одному или нажмите **Применить рекомендуемые** на странице. Для некоторых нужен перезапуск Проводника или перезагрузка.
3. На странице **Хоткеи и жесты** настройте жесты окон и сочетания клавиш. Закройте окно, PowerTools продолжит работать в трее. Включите **Запускать вместе с Windows** в настройках, чтобы программа стартовала при входе без запроса UAC.

Жесты окон и горячие клавиши
----------------------------

| Действие | По умолчанию |
| --- | --- |
| Переместить окно | `Win` + левая кнопка мыши, тянуть за любое место |
| Изменить размер окна | `Win` + правая кнопка мыши; за курсором идёт ближайший угол или край |
| Закрыть окно | `Win` + `Q` |
| Завершить процесс окна | `Win` + `Shift` + `Q` |
| Поверх всех окон (оранжевая рамка) | `Win` + `Alt` + `T` |
| Развернуть / восстановить | `Win` + `Alt` + `Enter` |

Модификаторы жестов и все сочетания меняются. Доступны и другие действия: свернуть, прозрачность окна, центрировать, на следующий монитор, запустить программу или открыть путь или ссылку. Программы, запущенные из сочетания, работают без прав администратора.

`Win+L`, `Ctrl+Alt+Del` и другие сочетания защищённого рабочего стола не может перехватить ни одна программа.

Технически
----------

- C++20, Win32 API и Dear ImGui на Direct3D 11. Без Electron, Qt и .NET.
- Один исполняемый файл со статическим CRT, около 0,9 МБ.
- Окно интерфейса создаётся по требованию и уничтожается при закрытии вместе со всеми ресурсами GPU. Кадры рисуются только при вводе или анимации.
- Хоткеи и жесты работают через низкоуровневые хуки клавиатуры и мыши в отдельном потоке и не зависят от интерфейса.
- Твики описаны таблицами значений реестра, типов запуска служб и задач планировщика; включение и откат берут данные из одного места.
- UWP-приложения удаляются по пакетам через PowerShell. Имена удалённых записываются в `%APPDATA%\PowerTools\removed_apps.txt`, чтобы их можно было зарегистрировать обратно.
- Настройки хранятся в `%APPDATA%\PowerTools\config.ini`.

Статус
------

Ранняя альфа. Собиралось и запускалось только на Windows 11. Часть твиков (например, политики меню «Пуск») может не работать на некоторых редакциях и сборках, а удаление приложений, близких к системе, может сломать зависящие от них функции. Если машина вам дорога, сначала создайте точку восстановления. Pull request-ы и issue приветствуются.

Сборка
------

Нужны Visual Studio 2022 (или Build Tools) с набором C++ и CMake 3.20+.

```
cmake -S . -B build -G "Visual Studio 17 2022" -A x64
cmake --build build --config Release
```

Результат: `build/Release/PowerTools.exe`. Dear ImGui лежит в `third_party/imgui`.
